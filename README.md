## Practical descriptions

- **A1.js – HTTP Server:** Creates a basic Node.js HTTP server and returns a welcome message.
- **A2.js – REST API:** Implements GET and POST routes for student records using Node.js HTTP module.
- **A3.js – File System:** Creates a text file, writes data, appends data and reads the file using Node.js `fs` module.

## Requirements

- Node.js installed on your computer.
- No external npm packages are required.

## How to run

Open a terminal in the `file` folder and run each command:

```bash
node A1.js
node A2.js
node A3.js
```

A3 creates `student_data.txt` inside the `file` folder when executed.
